**音沼の住民に向けた、DAC への受け渡しを細かく追い込むための仮想 ASIO ドライバ**です。旧名 BareStream Local から名前を変えた最初の公開版です。

再生ソフトからは普通の ASIO ドライバ 1 本に見え、その裏で DAC への受け渡し方式（ASIO 中継・WASAPI 排他・Kernel Streaming パケット / WaveRT）とバッファ・周期を、再生しながら切り替えて好みの音を探せます。ビットパーフェクト、ユーザーモードのみ（カーネルドライバ・署名不要）。

### 主な機能
- 出力方式: ASIO 中継 / WASAPI 排他（イベント・タイマー）/ KS パケット / KS WaveRT（自動判定）
- DSD: ASIO ネイティブ DSD で受け取り、ネイティブ（ASIO 中継）または DoP（上限を設定可能）で出力
- コントロールパネル: 起床間隔のばらつき・アンダーラン・パイプライン内ビット一致の表示、プリセット、ブラインド A/B（ABX）、タスクトレイ常駐
- `install.bat` / `uninstall.bat`（管理者として自動で実行し直す）

### インストール
zip を展開して `install.bat` をダブルクリックしてください。BareStream Local（旧名）を入れている場合は、旧版の登録・常駐・ショートカット・フォルダを自動で片付け、設定とプリセットは初回起動時に自動で引き継ぎます。旧版を使っている再生ソフトは、先に終了しておいてください。

再生ソフトの出力先は **OtonumaASIO** を選び直してください（ドライバ名が変わったため）。

### 動作確認
- SMSL D400EX + TuneBrowser: ASIO 中継（PCM・ネイティブ DSD）、WASAPI 排他（イベント駆動）、KS パケット（1000 Hz まで）、DSD256 DoP

### 注意
- 未署名の DLL のため、ウイルス対策ソフトが誤検知することがあります（除外設定の手順はマニュアルにあります）。
- BareStream ネットワーク出力は今後の版で統合予定です。
